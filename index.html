住宿

9/18｜福容大飯店花蓮

第一晚住花蓮港附近，隔天前往賞鯨方便。

連住兩晚。白鮑溪結束後入住，隔天玩海洋公園；若白鮑溪取消，也能直接提早享用飯店設施。

主線：
林口 → 福容花蓮 → 鯨世界 10:00 賞鯨 → 白鮑溪（視水況）→ 遠雄悅來 → 遠雄海洋公園 → 蘇花 → 宜蘭／蘇澳 → 台中

親子提醒

賞鯨前晚睡飽、早餐清淡；出航依當日海況。
白鮑溪準備防滑水鞋與完整換洗衣物；雨後或水況不佳直接取消。
備案邏輯賞鯨取消 → 考慮兆豐；只有溪水不適合 → 直接遠雄飯店。
